# JSON

JSON은 **JavaScript 객체 문법을 기반으로 한 구조화된 데이터 교환 형식**입니다.  
여러 언어에서 데이터 교환 형식으로 사용되며, 객체뿐만 아니라 배열, 문자열 등도 표현할 수 있습니다.

---

## 1. JavaScript 객체 문법

```json
{
  "name": "kundol",
  "age": 30
}
```

중복된 키가 존재하면 일반적으로 나중에 작성된 값이 적용됩니다.  
따라서 하나의 객체 안에서 키는 고유하게 작성하는 것이 좋습니다.

JSON 파일의 데이터를 JavaScript 객체로 사용하려면 `JSON.parse()`를 이용해 변환한 뒤 로직을 실행할 수 있습니다.

```json
[
  {
    "name": "kundol",
    "age": 30
  },
  {
    "name": "yang",
    "age": 30
  }
]
```

```json
{
  "name": {
    "firstname": "test",
    "lastname": "last"
  }
}
```

JSON은 배열 형태로도 사용할 수 있으며, 객체 안에 객체를 포함하는 재귀적인 구조도 표현할 수 있습니다.

---

## 2. 데이터 교환 형식

데이터는 추상적인 아이디어부터 구체적인 측정값까지 다양한 의미로 사용됩니다.  
JSON은 이러한 데이터를 시스템 간에 교환할 때 사용하는 형식입니다.

---

## 3. 여러 언어에서의 활용

JSON은 객체, 해시 테이블, 딕셔너리 등 여러 언어와 플랫폼에서 독립적으로 사용됩니다.

JavaScript와 Python의 버전이 계속 변경되더라도 JSON 형식 자체를 함께 변경할 필요는 없습니다.

---

## 4. 단순 배열과 문자열 표현

JSON은 보통 `key-value` 형태로 사용되지만, 단순 문자열이나 배열도 JSON으로 표현할 수 있습니다.

```json
["Java", "JavaScript", "Python"]
```

```json
"Hello JSON"
```

JSON은 비교적 느슨한 데이터 형식을 가지고 있으므로 스키마 설계에 주의해야 합니다.  
어떤 데이터를 어떤 형식으로 주고받을지 명확하게 정할 필요가 있습니다.

---

## JSON의 타입

JSON은 JavaScript 객체와 유사하지만 `undefined`와 메서드 등을 포함할 수 없습니다.

- 수 (`Number`)
- 문자열 (`String`)
- 논리값 (`Boolean`)
- 배열 (`Array`)
- 객체 (`Object`)
- `null`

---

## JSON 직렬화와 역직렬화

직렬화는 데이터를 외부 시스템에서도 전달하고 사용할 수 있는 형태로 변환하는 과정입니다.  
역직렬화는 전달받은 데이터를 다시 프로그램에서 사용할 수 있는 객체 형태로 변환하는 과정입니다.

JavaScript에서는 다음 메서드를 사용합니다.

```javascript
const json = JSON.stringify(object);
const object = JSON.parse(json);
```

예를 들어 JavaScript 환경에서 Python 환경으로 데이터를 전달하고, 데이터 형식으로 JSON을 사용한다면 `JSON.stringify()`를 이용해 JSON 문자열로 변환한 뒤 전달할 수 있습니다.

---

## JSON의 활용

JSON은 프로그래밍 언어와 프레임워크에 독립적이므로 서로 다른 시스템 간에 데이터를 교환하기에 적합합니다.

주로 다음과 같은 곳에서 활용됩니다.

- API 요청 및 응답 데이터
- 시스템 설정 파일
- 서로 다른 시스템 간 데이터 교환

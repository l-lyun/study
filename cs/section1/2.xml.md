# XML

XML은 **마크업 형태를 사용하는 데이터 교환 형식**입니다.

---

## 1. 마크업 형태

마크업은 태그 등을 이용해 문서나 데이터의 구조를 나타내는 방법입니다.  
각 요소에는 속성을 부여할 수도 있습니다.

```xml
<?xml version="1.0" encoding="UTF-8"?>

<person>
  <name>kundol</name>
  <age>30</age>
</person>
```

XML 문서는 일반적으로 다음과 같이 구성됩니다.

- **프롤로그**: XML 버전과 문자 인코딩 정보
- **루트 요소**: 문서 전체를 감싸는 하나의 최상위 요소
- **하위 요소**: 루트 요소 내부에 포함되는 요소

프롤로그는 필요에 따라 생략할 수 있지만, 루트 요소는 반드시 하나만 존재해야 합니다.

---

## 2. HTML과 XML의 차이

1. HTML은 주로 데이터를 화면에 표시하기 위해 사용하고, XML은 데이터를 저장하거나 전송하기 위해 사용합니다.
2. HTML에는 미리 정의된 태그가 있지만, XML에서는 사용자가 목적에 맞는 태그를 직접 정의할 수 있습니다.
3. XML은 태그의 대문자와 소문자를 구분하지만, 일반적인 HTML 문법에서는 태그 이름의 대문자와 소문자를 구분하지 않습니다.

```xml
<Name>kundol</Name>
```

```xml
<name>kundol</name>
```

XML에서는 위의 두 태그를 서로 다른 태그로 인식합니다.

---

## 3. JSON과 XML의 차이

XML은 여는 태그와 닫는 태그를 함께 작성해야 하므로 JSON과 비교했을 때 데이터의 크기가 커질 수 있습니다.

또한 JavaScript 객체로 변환할 때는 일반적으로 JSON보다 더 많은 처리 과정이 필요합니다.

### XML

```xml
<person>
  <name>kundol</name>
  <age>30</age>
</person>
```

### JSON

```json
{
  "name": "kundol",
  "age": 30
}
```

---

## 4. XML의 활용

XML은 특정 프로그래밍 언어에 종속되지 않으므로 여러 시스템에서 독립적으로 사용할 수 있습니다.

주로 다음과 같은 곳에서 활용됩니다.

- `sitemap.xml`
- 시스템 간 데이터 교환
- 설정 파일
- 문서 구조 표현
